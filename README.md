# 🛍️ Panduan Demo Website "Katalog Retail & Fashion UMKM"

Template ini ditujukan untuk pemilik brand fashion lokal, toko baju, produsen tas/sepatu, hampers, toko bunga (florist), dan aneka produk fisik UMKM.

---

## 📂 Lokasi File

`C:\Users\ACER\.gemini\antigravity\scratch\website-demo-katalog-fashion\index.html`

### Cara Membuka Demo:
Klik dua kali file `index.html` tersebut untuk langsung membukanya di browser Google Chrome / Edge Anda.

---

## 🛠️ Cara Kustomisasi
1. Buka file `index.html` dengan Notepad / VS Code.
2. **Ganti Nomor WhatsApp:**
   Cari baris sekitar 430:
   ```javascript
   const STORE_WA_NUMBER = "6281234567890";
   ```
   Ganti dengan nomor WhatsApp pemilik toko.
3. **Ganti Nama Brand:**
   Cari kata `LUMEN Studio` dan ganti dengan nama brand calon klien Anda.
